## 🛍️ Project Overview

**Zaree Fashion Retail Analytics** is an end-to-end retail analytics portfolio project built using **Microsoft Excel**.

Zaree is used as a local fashion retail business case covering products such as:

- 👰 Bridal Wear
- 👗 Lehengas
- 🥻 Sarees
- 👚 Kurtis
- 👔 Men's Fashion
- 🧒 Kidswear

The project starts with an intentionally messy retail transaction dataset and demonstrates the complete analytics workflow:

**Raw Data → Data Cleaning → Data Validation → Analysis → Visualization → Dashboard → Business Insights**

---

## 🎯 Project Objectives

The primary objectives of this project were to:

- 🧹 Clean and standardize a messy retail dataset
- 🔍 Identify data-quality issues and anomalies
- ✅ Validate the cleaned data
- 📊 Perform business-focused data analysis
- 📑 Create PivotTables and PivotCharts
- 📈 Build an interactive Excel dashboard
- 💡 Generate meaningful business insights
- 🗂️ Demonstrate a complete Data Analyst workflow

## ⚠️ Raw / Dirty Data

The raw dataset was intentionally created with realistic data-quality issues to simulate a real-world retail dataset.

### Data Issues Included

- 🔄 Duplicate records
- ❌ Missing values
- 📅 Inconsistent date formats
- 🔤 Inconsistent text values
- 🧹 Leading/trailing whitespace
- 🔢 Numbers stored as text
- ⚠️ Invalid discount values
- 🚫 Zero-quantity records
- 📝 Inconsistent city names
- 🛒 Inconsistent sales-channel names
- 💳 Inconsistent payment-method values

The raw dataset was kept unchanged to demonstrate the **before-and-after data cleaning process**.

---

## 🧹 Data Cleaning Process

The raw dataset was cleaned and prepared before analysis.

### 🔧 Cleaning Steps

1. 🔍 Inspected the raw dataset
2. 🔄 Identified duplicate records
3. 🧹 Removed duplicate records
4. 🔤 Standardized text values
5. 📅 Standardized date formats
6. 🔢 Converted text-based numbers into numeric values
7. ❌ Identified and handled missing values
8. ⚠️ Identified invalid and anomalous entries
9. ✅ Validated calculated fields
10. 📊 Prepared the final cleaned dataset for analysis

### ✅ Result

The cleaned dataset was structured and validated for use in:

- 📊 PivotTables
- 📈 PivotCharts
- 🧮 Calculated metrics
- 📉 Business analysis
- 📊 Dashboard development

## 💡 Key Insights

Based on the portfolio dataset:

- 💵 **Net Sales:** Approximately ₹8.9M
- 🧾 **Orders:** 1,000
- 📈 **Profit Margin:** Approximately 27%
- 🏷️ Moderate discount levels showed stronger sales performance than deeper discounts **in this dataset**.
- 📅 Sales performance varied across different periods.
- 👗 Product performance differed across categories and brands.
- 🔻 Losses were concentrated in selected categories.

> ⚠️ These findings are based on synthetic/structured portfolio data and are intended to demonstrate the analytical process, not actual company performance.
